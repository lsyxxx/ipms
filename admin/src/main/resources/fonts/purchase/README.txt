Noto Serif SC (Regular, weight 400)

Source: https://github.com/google/fonts/tree/main/ofl/notoserifsc
Original file: NotoSerifSC[wght].ttf
License: SIL Open Font License 1.1 (see OFL.txt).

The bundled static TrueType font was instantiated at weight 400 with FontTools.
It substitutes the templates' Chinese system fonts while preserving font sizes
and avoiding a dependency on fonts installed on the application server.
PDFBox embeds only the glyphs needed by each generated document.

Optional Spring configuration:
abt.pur.pdf.font=classpath:fonts/purchase/NotoSerifSC-Regular.ttf
An external, embeddable static TrueType font can be configured with file:/... .
