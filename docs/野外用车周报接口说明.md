# 野外用车周报接口

实现日期：2026-11-12。接口为 `GET /field-vehicle/weekReport`，返回现有 `R<FieldVehicleWeekReportVO>`；登录权限与用车列表一致，只读，无需负责人角色。不新增数据库字段、表或迁移脚本。

本接口以当前 `client_prod/src/views/fieldVehicle/weekReport.vue` 和[页面设计与数据定义](野外用车周报页面设计与数据定义.md)为依据。内部系统 index 中旧版周报的“本周还车整次加油、上周对比”口径不适用于本接口。

## 请求

示例：`/field-vehicle/weekReport?weekStart=2026-11-02&weekEnd=2026-11-08`。

| 参数 | 规则 |
| --- | --- |
| weekStart | 必填，yyyy-MM-dd，必须为周一 |
| weekEnd | 必填，yyyy-MM-dd，必须为同一自然周的周日 |
| carId | 可选，最多 50 字符，空白不筛选 |
| status | 可选，只允许 1 使用中、2 已结束；不传为全部正式记录 |

只使用上述四个筛选条件；继承的通用查询参数不参与周报统计。页面自行分页、查看行程详情和加油弹窗，不需要再请求详情或分页接口。

## 返回

| 字段 | 内容 |
| --- | --- |
| weekStart、weekEnd | 请求自然周，yyyy-MM-dd |
| queryDate、queriedAt | Asia/Shanghai 查询日期及查询时点；时点格式 yyyy-MM-dd HH:mm:ss |
| summary | 六项卡片及其统计覆盖信息 |
| resources | 全部命中车辆，id、title、order；按车牌排序 |
| events | 日历实际及预计事件；FullCalendar 的 end 为不包含的结束日期 |
| trips | 全部命中行程，按 useDate、createDate、id 降序 |
| weekFuelItems | 周内正常加油，按 fuelDate、id 升序 |
| pendingFuelItems | 周报行程内未填加油日期的记录，按 id 升序 |
| driveRows | 按车汇总；seq 从 1 开始，顺序与 resources 一致 |

`summary` 包含 outCarCount、weekCarCount、dispatchCount、usingCount、endedCount、weekFuelQuantity、weekFuelAmount、weekFuelCount、pendingFuelCount、usedMileage、abnormalMileageCount、fuelConsumption、consumptionFuelQuantity、consumptionMileage、consumptionTripCount。

`trips` 继承现有用车列表展示字段，新增 crossWeek、mileageValid、weekFuelQuantity、weekFuelAmount、fuelItems。fuelTotalQuantity、fuelTotal、fuelCount 按完整明细重算，不使用本周小计覆盖整次累计。usedMileage 为 statisticsEndMileage 减 statisticsStartMileage，无法取得有效起止读数时为空。statisticsStartDate、statisticsStartMileage、statisticsStartFuelId 为统计开始读数的日期、公里数和加油记录 ID；周前派车取上周最后一笔加油，本周派车取实际派车日期和公里数（开始加油 ID 为空）。statisticsEndDate、statisticsEndMileage 为统计结束读数的日期和公里数，statisticsFuelId 为截止日未结束时选中的加油记录 ID，statisticsFuelQuantity 为参考油耗采用的升数；原有 startMileage、endDate、endMileage、status 保留实际派车和当前还车信息。

`fuelItems` 继承现有加油展示字段，保留 id、mainId、fuelDate、fuelQuantity、amount、mileage、remark，另有 carNo、purpose、fuelScope；mileage 为可空表显公里数。fuelScope 为“本周”“本周未纳入统计”“其他周”“待确认日期”。“本周”表示实际参与本周加油统计，“本周未纳入统计”表示截止日未结束行程的周内其他加油。行程详情保留全部明细，包括其他周和无日期明细。

`events` 包含 id、resourceId、title、start、end、allDay、classNames、extendedProps。classNames 为 fv-done、fv-using 或 fv-expect；extendedProps 包含 tripId、crossWeek、line 及用车列表展示字段。line 为“实际用车”或“预计用车”。实际段最多画至 queryDate，预计段从 queryDate 次日与实际用车日期的较晚者开始；全部事件裁剪到查询周。不填或已过期的预计归还日期不生成预计段。

## 统计口径

所有区域先应用同一车辆、状态条件，排除草稿。周报行程 R 是本周派车 D、当前使用中且 useDate 不晚于周末的 U、周前派出且 endDate 不早于周一的跨周结束行程 C 的并集。

- 在外车辆按 U 的 carId 去重；本周用车按 D 与 U 的 carId 去重。
- 派车次数为 R 条数，等于使用中次数加已结束次数。
- 开始公里数：周前派车（useDate 早于 weekStart）必须取同一派车上周最后一笔加油的 mileage，上周范围为 weekStart 前 7 天至前一天。上周无记录或最后一笔缺少 mileage 时开始公里数为空，不退回派车公里数、本周第一笔或更早周记录。本周派车仍取实际 startMileage。
- 截止日已结束（endDate 不晚于 weekEnd）的行程，结束公里数取实际还车 endMileage，本周加油按周内明细合计。周前派车的参考油耗分子取本周升数，本周派车且截止日已结束时仍取整次升数。
- 截止日未结束（endDate 为空或晚于 weekEnd）的行程，结束公里数取 fuelDate 不晚于 weekEnd 的最近一条加油的 mileage。该笔日期落在本周时，其升数、金额、笔数及明细纳入本周加油和参考油耗分子；其余周内加油仅保留在完整行程明细中。该笔早于本周时，不重复统计其升数、金额和笔数。
- 最近加油按 fuelDate、createDate、id 降序确定，同日多笔只取排序首条。不选截止日之后或空日期的记录。最近记录缺少 mileage 时，里程保持未知，不退回更早记录或使用后来的还车读数；该笔升数、金额仍可参与本周加油。读数倒置等里程异常不计公里数并记入 abnormalMileageCount。
- 参考油耗只用 R 内统计里程大于零且统计升数大于零的行程，按同一批行程的升数合计除以公里数合计再乘 100，保留 1 位小数。没有可用加油或里程时油耗为空。

### 历史周和跨周期示例（2026-11-25 调整）

历史周始终以所选 weekEnd 判断是否已经结束，不能根据查询当天的 FINISHED 状态改用未来的最终里程。例如查询 10 月某周，车辆在该周末以后才还车，即使现在已经还车，也仍使用当周截止日前最近一笔加油读数和该笔升数；截止日之后的加油与最终还车里程不参与该周统计。若实际还车日期就在截止日或之前，则使用实际还车里程。

例如车辆上周派出、上周最后一笔加油表显 1,200 公里；本周截止日 11 月 25 日，24 日最近加油记录表显 1,600 公里、40 升，则开始公里数 1,200、结束公里数 1,600，本周统计公里数 400 公里，采用加油量 40 升；如该周另有更早的 30 升，本次截止日未结束行程不将它与 40 升合计。接口仍要求周一至周日的自然周，例中的任意日期用于说明截止取数规则。

持续使用时，本周开始读数承接上周最后一笔加油，结束读数取本周截止日前最近一笔加油，二者差值避免重复计入上周已经统计的里程。若本周没有新加油，则起止均为上周最后读数，可观测里程差为 0，不代表车辆实际未行驶；加油量、金额和笔数也不重复计入。读数只代表加油时点，不按天分摊，也不视为精确的周一零点或周日结束快照。

## 车辆行驶统计取值规则

这些规则补充页面新增字段的定义；周始、周末公里数表示本次统计采用的读数，日期来源可查看行程 statisticsStartDate、statisticsEndDate。

| 字段 | 取值 |
| --- | --- |
| carId、carNo | carId 分组；车牌取排序后最新命中行程的车牌快照 |
| dept | null，现有车辆和行程没有可靠部门字段 |
| weekStartMileage、weekEndMileage | 该车按 useDate、id 升序的首条行程统计开始读数及末条行程统计结束读数；缺失时为空，不用中间行程读数代替边界 |
| usedMileage | R 内该车有效统计结束读数减统计开始读数之和；周前派车从上周最后一笔加油读数起算，与卡片口径相同 |
| fuelQuantity、fuelAmount、fuelItems | R 内该车按上述截止规则选中的本周加油升数、金额及明细 |
| totalMileage | 同一车辆、状态筛选下，截至所选周末的全部有效野外行程里程合计；每条以派车实际 startMileage 为累计基准，截止日未结束的结束读数取最近加油 mileage。此字段为历史累计，与本周 usedMileage 的周初加油基准不同，非车辆表显总公里数 |
| totalAmount | 同一车辆、状态筛选下，正式行程内 fuelDate 不晚于所选周末的全部加油金额；无日期明细不累计 |
| fuelConsumption | 该车 R 内参考百公里油耗，分子分母规则同汇总卡片 |
| remark | 备注，可空；不自动填入统计口径或数据缺失说明，当前按车汇总无独立用户备注来源，保持为空 |

累计字段随状态条件变化，状态筛选及“当前在外”仍使用查询时点的当前状态，不是历史状态快照；里程及加油统计按所选周末截止。totalMileage 包含本周以前的行程，usedMileage 只包含 R 内行程。没有历史记录的可加总项为 0，未知边界读数和不可计算油耗为空。历史结果依据当前保存的业务日期数据重算；后来补录或修正截止日前的加油记录会改变历史统计，本接口不保存不可变的历史报表快照。

## 一致性、异常与兼容性

服务使用可串行化只读事务，先取正式行程，再按最多 500 个主记录 ID 分批读取加油。各区域从同一份内存数据聚合，避免逐行查详情；不展开一对多关联分页，不新增原生 SQL，兼容 SQL Server 2014。并发写入时可能等待读取事务释放锁，查询超时 30 秒。

正式行程缺失车辆或用车日期、使用中却有实际结束日期、已结束缺失或倒置结束日期，以及关联明细的数量、金额、日期非法时，返回业务异常，提示记录标识，不伪装为零结果。结束公里异常则通过异常里程数提示，其他信息仍可查询。只读取有正式主记录的关联加油；孤立明细不作为正常加油统计，周报不承担全库孤立数据审计。

无记录返回空数组、零合计及空油耗。数据库或事务失败按现有全局异常处理返回失败，前端应保留错误提示。
