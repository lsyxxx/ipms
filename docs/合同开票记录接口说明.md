# 按合同编号查询开票记录

## 请求

- 方法：`GET`
- 路径：`/wf/inv/find/byContractNo`
- 认证：沿用系统现有认证。
- 返回结构：`R<List<ContractInvoiceVO>>`。

| 查询参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| contractNo | string | 是 | 合同编号，对应合同的 `code`，精确匹配；不能仅包含空白字符 |

请求示例：

```http
GET /wf/inv/find/byContractNo?contractNo=HT20260001
```

## 查询规则

- 只返回该合同下业务状态为“审批中”或“已通过”、且未删除的开票记录。
- 无符合条件的记录时，`data` 返回 `[]`。
- 本接口不分页，未指定排序。
- 原返回字段及层级保持兼容，每条记录新增 `includeTax`。

## 新增返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data[].includeTax | boolean / null | 合同是否含税：`true` 含税，`false` 不含税；未找到对应合同时为 `null`，字段仍返回 |

数据来源：按 `contractNo` 匹配合同 `SaleAgreement.code`，读取 `SaleAgreement.includeTax`（表 `agr_sale` 的 `is_tax` 列）。它表示合同当前的含税设置，不是开票时的历史快照，也不是关联结算单的含税设置。同一合同下各条开票记录返回相同的含税标记。此变更不新增数据库字段，无需执行数据库脚本。

## 主要原有返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data[].id | string | 开票申请编号 |
| data[].contractNo | string | 合同编号 |
| data[].contractName | string | 合同名称 |
| data[].contractAmount | number | 合同金额 |
| data[].invoiceType | string | 发票类型 |
| data[].invoiceAmount | number | 开票金额 |
| data[].project | string | 项目名称 |
| data[].clientId / clientName | string | 客户 ID / 名称 |
| data[].businessState | string | 业务状态：审批中、已通过 |
| data[].settlementId | string | 关联结算单号 |
| data[].issueDate | string | 开票时间，`yyyy-MM-dd HH:mm:ss` |
| data[].issuerId / issuerName | string | 开票人 ID / 姓名 |
| data[].invoiceFile / invoiceRemark | string | 发票文件 / 开票备注 |
| data[].testNo | string | 检测编号，多个以逗号分隔 |
| data[].company | string | 业务所属公司 |
| data[].isSocial | boolean | 是否社会市场客户 |
| data[].createDate / updateDate | string | 创建 / 更新时间，`yyyy-MM-dd HH:mm:ss` |

其他原有开票信息、部门班组信息、流程任务信息和审计字段继续保留。除 `includeTax` 外，值为 `null` 的字段沿用原规则不输出。

## 响应示例

以下为节选，省略其他原有字段：

```json
{
  "code": 200,
  "bizCode": 0,
  "msg": "Success",
  "data": [
    {
      "id": "INV20260001",
      "contractNo": "HT20260001",
      "contractName": "检测服务合同",
      "invoiceType": "专票",
      "invoiceAmount": 1000.0,
      "businessState": "已通过",
      "includeTax": true
    }
  ]
}
```

响应外层分页相关字段沿用 `R` 默认值，本接口未设置总数；记录数量以 `data.length` 为准。

## 异常

`contractNo` 未传、为空串或仅含空白字符时，抛出 `BusinessException`，提示“合同编号不能为空”，由全局异常处理器统一返回。
